# LocalList

LocalList helps signed-in members search nearby second-hand listings.

## Established product behavior

- Search results can be filtered by category, price range, condition, and distance.
- The product calls authenticated customers **members**.
- Each saved search has a stable canonical search ID, even if filter labels later change.
- Members already have an in-app **Inbox**. Email delivery is not available.
- The member's account timezone is available to product features.
- Listing detail pages disappear when a listing is removed or expires.
