# PocketList

PocketList lets signed-in members create private shopping lists and check off items while shopping.

## Established product behavior

- Product copy calls authenticated customers **members**.
- Each list has a details screen and an overflow menu for list-level actions.
- The **My Lists** screen shows only lists available to the signed-in member.
- List names are visible anywhere a list is referenced.
- Existing form errors are shown beside the relevant field and announced to screen readers.
