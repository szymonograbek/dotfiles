# Jujutsu
The working copy is always a commit. Modified files and an empty working-copy description are not Git-style uncommitted work: describe the change rather than stopping or asking to commit it. Inspect and describe every change in the review range when handoff naming requires it. Never use git commands in a colocated jj repository.
